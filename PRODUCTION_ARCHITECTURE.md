# POLAR SENSE AI — Production Architecture Document (SIH26063)

## 1. System Overview & Principles
**POLAR SENSE AI** is an integrated Polar Science Outreach, Knowledge Repository, and Media Dissemination Portal designed for high scientific accuracy, persistent interactive AI pedagogy, and multi-format outreach.

### Core Architecture Principles:
1. **Strict Decoupling:** Presentation, Domain Business Services, AI Orchestration, and Data Persistence are strictly isolated.
2. **Provider Agnostic AI Layer:** All generative AI and embedding interactions go through the abstract `AIProvider` and `EmbeddingProvider` interfaces (supporting Google Gemini, OpenAI, Anthropic, and local Deterministic Demo engines).
3. **Deterministic Grounding & Zero-Hallucination Guardrails:** Every factual assertion generated by RAG or during Teaching Room interruptions is strictly tied to verified database document chunks with page/section provenance.
4. **Stateful Pedagogical Machine:** The AI Teaching Room maintains persistent session snapshots in the relational database, enabling real-time interruptions, grounded Q&A, and exact resumption across browser refreshes.

## 3. Frontend Architecture

### 3.1 Pages & Routes
* `/` — Landing portal, quick Grounded RAG query tester, live Indian polar stations telemetry, and feature showcase.
* `/repository` — Knowledge Hub with faceted filtering (by station, document type, year), chunk inspector, DOI previews, and 1-click "Teach Me This".
* `/explorer` — Polar Explorer with dual Arctic/Antarctic projection tabs, station deep-dives (Bharati, Maitri, Himadri, IndARC, Dakshin Gangotri), and linked expedition logs.
* `/tutor` — AI Lesson Studio where educators/students configure topic, learner level, duration, and generate structured lessons.
* `/teaching-room` — Teaching Room Hub and session launcher.
* `/teaching-room/[sessionId]` — Full interactive AI Teaching Room with live digital blackboard, voice narration, student interruption, and evaluation quiz.
* `/media` — Media Dissemination Studio for generating public science articles, policy briefs, social threads, infographics, and 60s video scripts.
* `/admin` — Admin dashboard with document upload & chunk extraction, metadata governance, and live database telemetry.

### 3.2 Component Breakdown
* `components/ui/` — Atomic UI elements (Buttons, Badges, Modals, Progress bars, Tooltips, Tabs).
* `components/knowledge/` — `DocumentCard`, `FacetedFilters`, `DocumentDetailModal`, `CitationViewer`.
* `components/blackboard/` — `BlackboardCanvas` (Hybrid SVG + Canvas progressive chalk renderer).
* `components/teaching-room/` — `TeacherAvatar`, `TeachingControls`, `InterruptionModal`, `QuizModal`.
* `components/explorer/` — `StationCard`, `StationInspector`, `ExpeditionTimeline`.
* `components/media/` — `OutreachStudio`, `ArticleViewer`, `SocialThreadViewer`, `VideoScriptTimeline`.
* `components/admin/` — `DocumentUploadModal`, `TelemetryCards`, `GovernanceQueue`.

### 3.3 State Management
* **Zustand (`useTeachingRoomStore`)**: Client-side state machine managing active lesson data, current section index, current action index, audio speech state, interruption modal, and grounded Q&A responses.
* **Server State Synchronization**: Changes to session status, progress, and conversation history are persisted via REST API to the database.

### 3.4 Teaching Room & Blackboard Engine
* **Digital Blackboard Protocol**: Visual actions are structured JSON directives (`WRITE_TEXT`, `DRAW_ARROW`, `DRAW_BOX`, `DRAW_CIRCLE`, `HIGHLIGHT`, `CLEAR_BOARD`).
* **SVG Vector Layer**: Guarantees crystal-clear typography, connected flowcharts, bounding boxes, and math symbols.
* **Progressive Chalk Animation**: Renders strokes progressively in sync with the teacher's script.
* **Interruption Lifecycle**:
  ```text
  [Active Step N] ──► (Student asks question) ──► [Pause & Save Snapshot to DB]
                                                          │
  [Resume Step N Exactly] ◄── (Student clicks Continue) ◄── [Grounded RAG Answer + Citations]
  ```

## 4. Backend & Service Architecture

### 4.1 Modular Services
* `services/ai/`: `AIProvider` interface with `GeminiProvider`, `OpenAIProvider`, and `DemoProvider` implementations.
* `services/rag/`:
  * `document-processor.ts`: Text extraction, cleaning, and metadata parsing.
  * `chunking-service.ts`: Semantic paragraph chunking with sliding window and keyword indexing.
  * `vector-store.ts`: Dual indexing (Cosine Similarity + BM25 keyword matching).
  * `retrieval-service.ts`: Hybrid retrieval with confidence thresholding.
  * `citation-service.ts`: Verifies citation DOIs and page numbers against database records.
* `services/lessons/`:
  * `lesson-generator.ts`: Pedagogical multi-section lesson generation.
  * `lesson-service.ts`: Lesson persistence, matching, and retrieval.
* `services/teaching/`:
  * `teaching-state-machine.ts`: FSM enforcing valid state transitions.
  * `interruption-service.ts`: Pauses active session, queries RAG, and logs Q&A turn.
  * `resume-service.ts`: Restores session snapshot and continues playback.
  * `teaching-engine.ts`: Session lifecycle and action advancement coordinator.
* `services/media/`: `media-generator.ts` producing multi-format dissemination content with provenance links.
* `services/explorer/`: `explorer-service.ts` querying stations, sensor payloads, and expeditions.
* `services/documents/`: `document-service.ts` managing repository queries and system telemetry.

## 5. AI Pipelines & Flowcharts

### 5.1 RAG Knowledge Ingestion & Retrieval Pipeline

```
[Document PDF/Text]
       │
       ▼
[Text Extraction & Cleaning]
       │
       ▼
[Semantic Chunking (500 tokens, 100 overlap)]
       │
       ▼
[Dual Indexing] ──┬──► [Dense Vector Index (1536-dim Cosine Similarity)]
                  └──► [Sparse Inverted Index (BM25 Keywords)]
                              │
                    (User Query Submitted)
                              │
                              ▼
                  [Hybrid Search: 0.65×Dense + 0.35×Sparse]
                              │
                              ▼
                  [Top Verified Evidence Chunks]
                              │
                              ▼
                  [Grounded System Prompt Injection]
                              │
                              ▼
                  [Multi-Provider LLM Call]
                              │
                              ▼
                  [Citation Verification Engine]
                              │
                              ▼
                  [Grounded Answer + Verified Citation Badges]
```

### 5.2 AI Teaching Room Execution & Interruption Lifecycle

```
[Lesson Loaded]
       │
       ▼
[Section 1: EXPLAINING] ──► [Narration & Chalkboard Cues]
       │
       ▼
(Student Clicks "Ask Question")
       │
       ▼
[PAUSE STATE CAPTURED] ──► (Section ID, Action Index, Board Snapshot saved to DB)
       │
       ▼
[Grounded RAG Retrieval] ──► (Searches paper chunks for student inquiry)
       │
       ▼
[Grounded Teacher Explanation] ──► (Rendered in Q&A overlay with citations)
       │
       ▼
(Student Clicks "Continue Lesson")
       │
       ▼
[RESUME EXACT ACTION STATE] ──► (Continues next chalk stroke / section smoothly)
```
